# UrbanNest Retail

## Project Overview

UrbanNest Retail is an e-commerce platform project designed to provide customers with a smooth online shopping experience.

## Project Objectives

- Build an easy-to-use online shopping platform.
- Allow customers to browse products.
- Enable customers to add products to their cart.
- Provide a secure checkout experience.

## Project Scope

The project includes product browsing, shopping cart functionality, checkout, payment integration and order management.

## Project Status

Project planning and requirements gathering.
